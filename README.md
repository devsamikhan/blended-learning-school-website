# Blended Learning School Web Platform

Welcome to the official repository for the **Blended Learning School Website**. This platform is engineered to drive the digital transformation of educational infrastructure, combining a high-integrity React frontend with dynamic shadcn-ui components and a robust systems backend.

## Quick Start (Local Development)

If you want to run this project locally on your machine, ensure you have Node.js and npm installed, then execute the following commands in your terminal:

```sh
# Step 1: Clone the repository to your local system
git clone [https://github.com/devsamikhan/blended-learning-school-website.git](https://github.com/devsamikhan/blended-learning-school-website.git)

# Step 2: Navigate into the project root directory
cd blended-learning-school-website

# Step 3: Install all required production and development dependencies
npm install

# Step 4: Boot up the development engine with hot-reloading
npm run dev:all
